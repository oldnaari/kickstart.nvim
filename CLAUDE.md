# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Git workflow

This is a private fork, worked on solo. **Commit and push directly to `master`.**

- Do not create feature branches.
- Do not open pull requests.
- The default branch is `master`, not `main`.

This overrides the usual "branch before committing to the default branch"
default. It is deliberate: there is no one to review a PR, so a branch only adds
a merge step.
